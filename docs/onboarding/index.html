WHY TWO ENCODERS?

Isolation is deliberate.

The bootstrap runtime writes protobuf by hand. The Kotlin model reads it with kotlinx.serialization. The agent does not depend on the model or inject Kotlin dependencies into the app.

WHY WRITE FIRST?

The file is the transport’s anchor.

Late live clients read from byte one, then follow new frames. Recorded and live inputs share a format. After a crash, complete frames already written remain readable.

UNDERSTAND THE CONTROLS

Pause has a precise meaning.

Events, not instructions.A computation loop with no observed event keeps going.

Threads are held.A coroutine retains its thread; others on that event loop wait too.

Time keeps moving.Timeouts may fire on release. Slowdown changes interleavings.

Pace is per sequence.Parallel coroutines keep independent rates; this is not one global queue.

Gate waits are not fake blocking events. Held duration and setting changes are recorded separately. When the last controller leaves, the gate returns to its configured pace, unpauses, and drops subtree overrides.

The contracts worth protecting.

01

Keep the agent invisible.

Hooks run inside JDK and coroutine internals. Guard reentrancy, catch Throwable, and never leak a failure into application code. Bootstrap runtime stays dependency-free Java.

Hooks.java ↗
02

Change both wire definitions.

TraceEncoder/Wire and Trace.kt implement the same contract independently. Change both, update the format document, and verify through a real agent trace.

TRACE_FORMAT.md ↗
03

Geometry is a promise.

Boxes stay separated. Distinct lines never share a segment; crossings are at right angles. The independent checker tests shapes, not the router’s assumptions.

InvariantChecker.kt ↗
04

Keep wording and logic central.

Event and node wording lives in Labels.kt. GUI behavior belongs in view/ or source/; composables stay thin. Plugin task state must survive configuration cache.

Contributor conventions ↗
Touching instrumentation or pacing? Read these sharp edges. ＋

Class loading: ASM uses COMPUTE_MAXS, not frame recomputation. Injected code is branch-free; warm up transformer paths before installation. JDK retransformation cannot change class shape.

Hook paths: no lambdas or invokedynamic in bootstrap hooks. Kotlin objects cross the boundary as Object; access goes through method handles.

The gate: wait only at the audited Pace.await point, after discovering relevant nodes and before reading state or taking locks. Use Thread.sleep; parking would consume an application park permit. Never gate inside Tracer.emit.

Duplicated plugin contracts: properties, source-index encoding, and native-probe paths are mirrored on purpose. Keep both ends aligned. AgentConfigTest pins properties and the index.

Practical limits before you rely on a trace ＋

Development tool: stack and context values are recorded verbatim; coroutine-heavy code can take a multiple of its normal runtime. Use it without competing coroutine agents such as kotlinx-coroutines-debug or the IDE debugger’s coroutine agent.

Platform coverage: only macOS arm64 has been exercised end to end. Windows remains untested; its native probe build is not scripted. Without a native probe, monitor contention is missing while other capture continues.

Capture limits: executor task nodes, virtual-thread mount/pin events, Flow/channel semantics, and file I/O tracing are not implemented. Only the first copy of kotlinx.coroutines in a JVM is traced. Direct startCoroutineUninterceptedOrReturn with a custom completion can remain unseen; generators are intentionally hidden.

Reader + source lookup: recorded files are read once; use a live session to follow a running process. Custom-named KMP JVM targets have a dependency source-index gap. Nothing has been published to a public artifact repository.
